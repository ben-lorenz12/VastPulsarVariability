# VastPulsarVariability
VAST Pulsar Variability Project


## Get_control_stats

This file contains methods to pull data for potential control sources to use for comparison to known pulsars.

## Get_psr_statsandplots

This file contains methods to pull data for known pulsars, create a dataframe containing relevant quantities for these pulsars, and create plots for these pulsars.

## Single_psr_plotsandstats

This file contains machinery to calculate correlations between pulsars and their control sources, and to create normalized fluxes for each pulsar with respect to their control source. Also contains some code for making lightcurves and getting images for each pulsar observation.
